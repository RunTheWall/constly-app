# Roadmap

Constly ships one release at a time. This is direction, not a schedule: no
dates, and priorities move with what people actually ask for. The best way to
shape it is to open an issue, or give a thumbs-up to one that already exists.

## Recently shipped

- Native Linux builds (`.deb`, `.rpm`, tarball)
- Per-architecture macOS builds for Apple Silicon and Intel, each about half the
  size of the old universal binary
- Homebrew install: `brew install --cask runthewall/tap/constly`

## What we are working toward

- **Wider reach.** More package managers and app stores, so Constly is one
  command away wherever you already install things.
- **Cleaner exits.** More export formats, so a finished document leaves Constly
  intact.
- **Fewer small frictions.** The daily-writing rough edges, reported in Issues
  and fixed in order.

For what has already landed, see the [release notes](CHANGELOG.md). Have
something you want? [Open an issue](https://github.com/RunTheWall/constly-app/issues/new/choose).
